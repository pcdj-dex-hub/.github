## Tips and Tricks for Smooth Performance

- Organize your library with playlists by energy, genre, and BPM for faster selection
- Set cue points and loops in advance to keep transitions clean during live sets
- Use headphone preview to align beats before bringing a new track into the mix
- Keep video files on a fast drive to reduce lag during visual performances
- Test controller mapping and audio routing before each event
- Keep a backup playlist ready for requests, breaks, and technical pauses
